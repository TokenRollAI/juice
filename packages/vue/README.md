# @tokenroll/juice-vue

Native Vue 3 tactile UI components, micro-interactions, headless composables, AI agent blocks, concentric `color-mix` tokens, and procedural Web Audio sounds for Juice UI.

- **Website & Interactive Playground**: https://juice.tokenroll.ai
- **Repository**: https://github.com/TokenRollAI/juice
- **Agent Skill**: `npx skills add TokenRollAI/juice`

## Install

```bash
pnpm add @tokenroll/juice-vue
```

## Quickstart

```ts
import '@tokenroll/juice-vue/styles.css';
import { JProvider, JStateButton, JToolApprovalGate } from '@tokenroll/juice-vue';
```
